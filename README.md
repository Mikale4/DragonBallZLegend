# Dragon Ball Z: Legend of the Z Fighters

An unofficial, non-commercial Dragon Ball Z fan game in a single HTML file (`index.html`). Play it at
https://mikale4.github.io/DragonBallZLegend/

Dragon Ball belongs to Akira Toriyama, Bird Studio, Shueisha, Toei Animation and Bandai Namco. Every fighter, place and
effect is drawn by the game itself; no official assets are used.

Progress saves in the browser you play in.

Run it locally: `python -m http.server 8765 --bind 127.0.0.1`, then open http://127.0.0.1:8765/
